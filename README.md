# Paint Online

Совместный графический редактор: несколько человек открывают одну ссылку и рисуют на общем холсте в реальном времени.

**Стек:** React 19, TypeScript 6, MobX 7, react-router 8, Canvas API, Vite 8, SCSS-модули — клиент; Node 24, Express 5, `express-ws` (WebSocket), TypeScript 6 — сервер.

## Возможности

- сессия по уникальной ссылке: адрес `/` перенаправляет на новую сессию, ссылкой можно пригласить других;
- инструменты: кисть, прямоугольник, круг, линия, ластик; цвет и толщина линии;
- совместное рисование по WebSocket: действия каждого участника сразу видны остальным;
- снимок холста хранится на сервере, поэтому вошедший позже видит уже нарисованное;
- отмена и повтор действия (undo/redo), сохранение рисунка в PNG.

## Запуск

Два терминала:

```bash
cd server
npm install
npm run dev     # http://localhost:5000, WebSocket: ws://localhost:5000/
```

```bash
cd client
npm install
npm run dev     # http://localhost:5173
```

Откройте `http://localhost:5173`, введите имя и скопируйте адрес сессии во второе окно, чтобы рисовать вдвоём. С другого устройства в той же сети: `npm run dev -- --host` в `client` и адрес компьютера вместо `localhost`.
